Sección 2 · Tecnología y arquitectura

Herramientas gratuitas y mantenibles

El stack es de uso común en la UTPL y fácil de mantener por un equipo pequeño. La ingesta queda separada para cambiar la carga de Excel por una API de Z-BioTime en el futuro.

CapaTecnologíaPara qué se usa
FrontendReact 18 + Vite + TypeScriptAplicación web de una sola página
EstilosTailwind CSS con tokens de marcaPaleta, tipografía y logo reemplazables
GráficosRechartsIndicadores de asistencia, headcount y rotación
BackendPython 3.12 + FastAPIAPI REST y reglas de negocio
Procesamiento de Excelpandas + openpyxlLee los reportes de Z-BioTime y exporta .xlsx
Exportación a PDFReportLabResumen de nómina y panel de indicadores
Base de datosPostgreSQL 16 (SQLite en local)Empleados, horarios, marcaciones, solicitudes, cargas y usuarios
Acceso a datosSQLAlchemy + AlembicModelos y migraciones versionadas

Pruebaspytest, Postman y PlaywrightReglas de negocio, API y recorrido de pantallas
